# Agentes locais do Antigravity

Estas definições são descobertas pelo Antigravity no escopo deste repositório.
Elas não iniciam tarefas, não criam recursos em nuvem e não usam Gemini API.

No Antigravity 2.0, abra o projeto e use `/agents` para conferir os perfis. Para
uma equipe paralela, inicie uma conversa nova e use o conteúdo de
`teamwork-prompt.md` com `/teamwork-preview`. A execução deve permanecer no
plano já contratado, sem habilitar cobrança por API ou Google Cloud.
